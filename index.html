How to Operate

  1. Set today's rotor key with the ▲▼ thumbwheels above each window.
  2. Wire the plugboard — click two letters to patch them.
  3. Type your message, on the keys below or your own keyboard.
  4. Watch the lamps light up — that's your ciphertext, also collected on the tape below the machine.
  5. Mistyped a letter? Hit Reset Machine and start the message over — there's no backspace on the real thing.

Why It Mattered

Enigma was one of the most powerful ciphers of the 20th century. Without the day's key — rotor order, starting positions, plugboard pairs — an intercepted message was practically unreadable, which is exactly why the Wehrmacht trusted it for secret communication.

Symmetric Key

Both ends used a copy of the same key, reset every few days. Fast to operate in the field — but anyone who obtained that day's key could read everything sent under it.

Path of One Letter

Key → plugboard → rotor III → II → I → reflector B → back through I → II → III → plugboard → lamp. Watch the trace panel above the tape — it lights up the same way, live, as you type.

Why the Rotors Turn

Every keystroke steps rotor III. A notch (letter W here) advances rotor II; a second notch (letter F) then advances rotor I. Because the rotors keep moving, the same letter typed twice almost never ciphers the same way twice — which is exactly what defeats simple frequency analysis.
